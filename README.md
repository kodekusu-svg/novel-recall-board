# ノベ磁針(仮)

小説を書きながら、キャラクター、呼称、登場履歴、用語、シーン本文をまとめて管理するための静的Webアプリです。

長編の途中で、誰が誰をどう呼ぶか、最後にどこで何をしたか、用語や設定をどこに書いたかを見失わないための創作補助ボードです。

## できること

- シーンごとに話数、タイトル、本文、登場キャラを記録
- シーン本文の文字数カウント
- シーン本文の置換、段落字下げ、直前の置換・字下げ操作のUndo
- 本文から登録済みキャラクターの登場を検出
- 解析用本文から名前候補や呼称候補を抽出
- キャラクターの名前、あだ名、一人称、色、備考、追加プロフィール項目を管理
- キャラクター一覧のドラッグ並べ替え
- 呼称表で、誰が誰を何と呼ぶかをマトリクス表示
- 同一人物セルに一人称を表示
- キャラクターごとの最終登場、登場履歴検索
- 用語名、別名、詳細メモを管理
- 用語が登場するシーンを検索し、該当シーンへジャンプ
- 名前抽出の判定フィードバックをGoogle Apps Scriptへ送信
- JSONで作品データをバックアップ・復元

## 使い方

`index.html` をブラウザで開くと動きます。GitHub Pagesでもそのまま公開できます。

読み込むファイルは以下です。

- `index.html`
- `styles.css`
- `text-tools.js`
- `app.js`
- `README.md`

作品データはブラウザの `localStorage` に保存されます。別端末や別ブラウザには自動同期されません。

## バックアップ

ブラウザ内保存だけだと、ブラウザデータ削除や端末変更で内容が失われます。重要な作品では、右上の書き出しボタンから定期的にJSONを書き出してください。

JSON読み込み時は、壊れた項目や形式の合わない項目をできるだけ無視・補正して読み込むようにしています。

## フィードバック送信

名前候補を「名前として採用」または「人名ではない」と判断した履歴を、精度向上フィードバックとして送信できます。

送信されるのは判定情報だけです。本文そのもの、前後文、作品名は送信しません。

Googleスプレッドシートへ蓄積する場合は、`google-apps-script/Code.gs` をApps Scriptへ貼り付けてWebアプリとしてデプロイします。アプリ側には送信先URLが組み込み済みなので、通常利用者がURLを入力する必要はありません。

## 公開メモ

GitHub Pagesで公開する場合は、このフォルダのファイルをリポジトリへ置き、Pagesを有効にします。

現在は完全な静的アプリです。ログイン、サーバー保存、ユーザー間共有はありません。
